# AI DLC — planned shared lifecycle service

Own intake, approved specifications, implementation jobs, budgets, bounded repair, verification routing, release manifests, and improvement intake.

Input: application manifest and approved intent. Output: versioned candidate and release evidence. Code, prompts, models, tools, policies, content, and domain-pack changes all enter the lifecycle.

`lifecycle.json` is a design contract, not an executable workflow. Implement persistent transitions and approval enforcement before claiming release automation. Models cannot grant permissions or approve their own release.
